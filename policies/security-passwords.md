# Passwords and Multi-Factor Authentication

## Passwords
Use the company password manager for every work account. Passwords must be at least 14 characters long and unique to each account. Never reuse a work password on a personal site.

## Multi-factor authentication
Multi-factor authentication (MFA) is required on email, the HR portal, the Expenses app, and source code hosting. Use the authenticator app or a hardware key; SMS codes are not allowed.

## Sharing
Never share a password or an MFA code with anyone, including IT staff. IT will never ask for them.
