# Using AI Tools Safely

You may use the company AI assistant for any Internal or Confidential data. Public AI chat tools that are not approved by IT may only be used with Public data. Never paste Restricted data, such as salaries, health information, or passwords, into any AI tool. Check every answer from an AI tool before you act on it; you are responsible for the result. The list of approved AI tools is on the IT intranet page.
